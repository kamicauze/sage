## API Usage

### Endpoint: `POST /builds/build-with-git`

**Request:**
```json
{
  "manifest_path": "architect/projects/my_app.yaml",
  "git_options": {
    "auto_commit": true,
    "commit_message": null,  // null = auto-generate
    "create_branch": "feature/my-feature",
    "push_to_remote": true,
    "files": null  // null = all generated files
  }
}
```

**Response:**
```json
{
  "status": "SUCCESS",
  "artifacts": ["src/auth.py", "tests/test_auth.py"],
  "files_built": [],
  "test_results": null,
  "summary": "Build completed successfully",
  "git_result": {
    "success": true,
    "workflow": [
      ["create_branch", {"success": true, "branch": "feature/my-feature"}],
      ["commit", {"success": true, "commit_hash": "abc1234", "message": "..."}],
      ["push", {"success": true}]
    ],
    "commit_hash": "abc1234"
  }
}
```

**Error Handling:**
```json
{
  "status": "SUCCESS",  // Build still succeeds
  "git_result": {
    "success": false,
    "error": "Git operation failed: Branch already exists"
  }
}
```

## Architecture

```
┌──────────────────────────────────────────────────────┐
│                     USER                              │
│                                                       │
│  Opens http://localhost:3000/build                   │
│  Generates plan → Enables Git options → Builds       │
└────────────────────┬─────────────────────────────────┘
                     │
                     ▼
┌──────────────────────────────────────────────────────┐
│            NEXT.JS UI (Port 3000)                     │
│                                                       │
│  Build Page:                                         │
│  - Git options form (checkboxes, inputs)             │
│  - Calls architectAPI.executeBuildWithGit()          │
│  - Displays git_result in build output              │
└────────────────────┬─────────────────────────────────┘
                     │ HTTP POST
                     │ /builds/build-with-git
                     ▼
┌──────────────────────────────────────────────────────┐
│         FASTAPI BACKEND (Port 8000)                   │
│                                                       │
│  builds_git.py:                                      │
│  1. Execute build (generate code)                    │
│  2. If success && git_options:                       │
│     a. Initialize GitMCPClient(repo_path)            │
│     b. Generate commit message (if needed)           │
│     c. Call auto_commit_and_push()                   │
│  3. Return BuildResponse with git_result             │
└────────────────────┬─────────────────────────────────┘
                     │
                     ▼
┌──────────────────────────────────────────────────────┐
│         GIT MCP CLIENT (shared/mcp/)                  │
│                                                       │
│  GitMCPClient:                                       │
│  - get_status()                                      │
│  - create_branch(name)                               │
│  - add_files(files)                                  │
│  - commit(message, files)                            │
│  - push(remote, branch)                              │
│  - auto_commit_and_push() [orchestrates all]         │
└────────────────────┬─────────────────────────────────┘
                     │
                     ▼
                ┌─────────┐
                │   GIT   │
                │  REPO   │
                └─────────┘
```

## Configuration

### Project Manifest

No changes required! Existing projects work automatically.

Optional: Add Git configuration to manifest:
```yaml
# architect/projects/my_app.yaml
project:
  id: my_app
  paths:
    repo_path: /home/user/projects/my-app  # Used by Git MCP

mcp:
  enabled: true
  servers:
    - name: git

      auto_commit: false  # Default
```

## Troubleshooting

### Issue: "Git operation failed: Not a git repository"
**Solution:** Ensure repo_path in manifest points to a valid git repo

### Issue: "Git operation failed: Branch already exists"
**Solution:** Use a different branch name or delete the existing branch

### Issue: "Permission denied"
**Solution:** Ensure git SSH keys are configured for push operations

### Issue: Build succeeds but no git result
**Solution:** Check that auto_commit is enabled in the request

### Issue: Can't access n8n UI
**Solution:**
```bash
docker ps | grep n8n  # Verify container running
docker logs n8n       # Check logs
```
